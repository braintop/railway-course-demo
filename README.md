# railway-course-demo

קוד הדוגמה לסדרת המפגשים על Railway. כל תיקייה היא מפגש, וב-Railway מגדירים אותה כ-Root Directory.

| תיקייה | מפגש |
|---|---|
| `02-array-api` | REST API ראשון: Express עם מערך |
| `03-mysql-api` | tasks עם MySQL |
| `04-docker-api` | Dockerfile ו-docker compose |
| `05-postgres-api` | tasks עם Postgres |
| `06-mongo-api` | tasks עם MongoDB |
| `07-client` | קליינט Vite |
